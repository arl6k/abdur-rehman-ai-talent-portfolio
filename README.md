# Abdur Rehman — AI & Talent Acquisition Portfolio

Personal portfolio focused on practical AI in recruitment and HR operations.

## Featured work
- Claude-connected employee testing system generating role-specific assessments from job descriptions.
- AI-assisted onboarding workflows using ChatGPT, Excel and PrismHR / Key HR.
- Personal projects: Vibe Track, Checkmate, OpenFrame Studio and NEO.
- Browser-only talent discovery demonstration; it calls no AI API and stores no candidate information.

## Run and deploy
Serve this directory with any static HTTP server. Deploy on Vercel with framework Other, no build command and the repository root as output. No dependencies, API keys or environment variables are required.

The portfolio preserves the supplied design and project links. Contact email, verified LinkedIn URL, CV file and a public assessment-system demo have not been supplied.
