01 / FLAGSHIP HIRING PROJECT

AI-powered candidate testing system.

I created an employee/candidate testing system connected with Claude that prepares assessments according to the job description. Rather than giving everyone a generic test, the idea is to start with the requirements of the actual role.

  • Job description as the assessment starting point
  • Claude-assisted generation of role-relevant tests
  • Designed to make candidate assessment more structured
